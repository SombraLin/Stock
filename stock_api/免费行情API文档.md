# 免费公开行情 API 文档

> 整理自本次数据采集实际使用的接口，以及常用的免费备选源。均为公开接口，无需注册、无需 API Key。
> 使用建议：加 `User-Agent` 头模拟浏览器；控制请求频率（1~3 秒/次）避免被封禁。

---

## 一、东方财富（本次 1 分钟分时数据来源）

### 1. 分时数据（逐分钟，最多近 5 个交易日）

```
GET https://push2his.eastmoney.com/api/qt/stock/trends2/get
```

| 参数 | 说明 |
|---|---|
| `secid` | 证券标识：市场前缀 + 代码。沪市 `1.xxxxxx`，深市 `0.xxxxxx`。如上证指数 `1.000001`，招商银行 `1.600036` |
| `ndays` | 返回天数，**最大 5**（即最多 5 个交易日的逐分钟数据） |
| `iscr` | 是否复权场景，一般传 `0` |
| `fields1` | 返回的元信息字段，如 `f1,f2,f3` |
| `fields2` | 返回的数据字段：`f51`时间 `f52`开 `f53`收（现价） `f54`高 `f55`低 `f56`成交量 `f57`成交额 `f58`均价 |

响应结构：`{"data": {"code": "...", "name": "...", "trends": ["2026-10-23 09:30,3623.57,3623.57,...", ...], "preClose": ...}}`，`trends` 为逗号分隔字符串数组，字段顺序与 `fields2` 对应。

**限制**：1 分钟粒度只能取最近 5 个交易日；当天盘中调用则包含当日实时分钟数据（约 3~5 秒延迟）。

### 2. 历史 K 线（支持 1/5/15/30/60 分钟、日/周/月）

```
GET https://push2his.eastmoney.com/api/qt/stock/kline/get
```

| 参数 | 说明 |
|---|---|
| `secid` | 同上 |
| `klt` | K 线周期（分钟）：`1`/`5`/`15`/`30`/`60`；日线 `101`，周线 `102`，月线 `103` |
| `fqt` | 复权：`0` 不复权、`1` 前复权、`2` 后复权 |
| `beg` / `end` | 起止日期，格式 `YYYYMMDD`；日线/分钟线历史范围受服务器限制 |
| `lmt` | 最大返回条数 |
| `fields2` | 同上（f51~f58） |

响应：`{"data": {"klines": ["2026-10-29 09:31,3676.77,3667.83,3676.77,3662.95,19360565,32713302784.00,0.38", ...]}}`

**实测限制**：`klt=1` 目前仅返回当日盘中数据；5 分钟及以上周期可取更长历史。

### 3. 实时行情快照

```
GET https://push2.eastmoney.com/api/qt/stock/get?secid=1.600036&fields=f43,f44,f45,f46,f47,f48,f57,f58
```
`f43` 最新价 `f44` 最高 `f45` 最低 `f46` 今开 `f47` 成交量 `f48` 成交额 `f57` 代码 `f58` 名称（价格字段一般需除以 100 或 1000，视品种而定）。

## 二、新浪财经（本次 5 分钟线来源）

### 分钟 K 线

```
GET https://quotes.sina.cn/cn/api/jsonp_v2.php/var%20_=/CN_MarketDataService.getKLineData?symbol=sh600036&scale=5&ma=no&datalen=1920
```

| 参数 | 说明 |
|---|---|
| `symbol` | 交易所前缀 + 代码：`sh000001`（上证指数）、`sh600036`（招商银行）、`sz000001` 等 |
| `scale` | K 线周期（分钟）：仅支持 **`5`、`15`、`30`、`60`**（不支持 1 分钟） |
| `datalen` | 返回条数，实测最大约 **1920**（5 分钟线约 2 个月） |
| `ma` | 是否带均线，传 `no` |

返回 JSONP，括号内为 JSON 数组：`[{"day":"2026-10-29 10:05:00","open":"...","high":"...","low":"...","close":"...","volume":"...","amount":"..."}]`（数值为字符串）。

## 三、腾讯行情（备用源）

### 分钟 K 线

```
GET https://web.ifzq.gtimg.cn/appstock/app/kline/mkline?param=sh000001,m1,,320
```

| 参数 | 说明 |
|---|---|
| `param` | `代码,周期,起始,条数`。周期 `m1`/`m5`/`m15`/`m30`/`m60`；代码如 `sh000001`、`sh600036` |
| 条数 | m1 实测约 320 条以内（约 1.5 个交易日） |

### 当日分时（逐分钟）

```
GET https://web.ifzq.gtimg.cn/appstock/app/minute/query?code=sh000001
```
返回 `data.sh000001.data.data` 为 `HHMM 价格 累计成交量` 格式数组，仅当日。
